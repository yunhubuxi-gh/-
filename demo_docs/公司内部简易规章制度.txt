公司内部简易规章制度（演示版）

==================== 第一章 考勤管理 ====================

第一条 工作时间
公司实行标准工时制，工作时间为每周一至周五。
上午上班时间：09:00
下午下班时间：18:00
中午休息时间：12:00 至 13:30

第二条 打卡要求
全体员工须在上下班时通过考勤系统打卡。
漏打卡须在 3 个工作日内提交补卡申请，由直属主管审批。

第三条 迟到与早退
迟到：晚于 09:00 到岗视为迟到。
早退：早于 18:00 离岗视为早退。
当月累计迟到或早退超过 3 次，每次扣除当日半小时工资。

第四条 请假类型
请假分为以下类型：
1. 事假：需提前 1 个工作日申请，由直属主管审批。
2. 病假：需附医院证明，由直属主管审批，超过 3 天须报人事部门备案。
3. 年假：入职满 1 年享 5 天年假，须提前 3 个工作日申请，由部门负责人审批。
4. 调休：加班后可申请调休，须在 1 个月内使用完毕。

==================== 第二章 文件权限管理 ====================

第五条 文件密级
公司文件按密级分为四类：
1. 公开：可在公司内部自由查阅。
2. 内部：仅限本公司员工查阅。
3. 机密：仅限相关部门及授权人员查阅。
4. 绝密：仅限指定人员查阅，须单独授权。

第六条 知识库权限
公司知识库实行四级权限管理：
1. 所有者（owner）：拥有知识库全部权限，可删除知识库、管理所有成员。
2. 管理员（admin）：可管理成员、修改知识库配置。
3. 编辑（write）：可上传、编辑、删除文档。
4. 只读（read）：仅可检索和查看知识库内容，不可上传或修改。

第七条 权限申请
需要更高权限访问文件的，须填写《权限申请单》，由知识库所有者或部门负责人审批。

==================== 第三章 审批流程 ====================

第八条 报销审批流程
报销按以下流程进行：
1. 员工在报销系统提交报销申请，并上传发票凭证。
2. 直属主管在 2 个工作日内审批。
3. 金额超过 5000 元的，须部门负责人加签。
4. 财务部门在收到审批通过后的 5 个工作日内打款。

第九条 请假审批流程
1. 员工提交请假申请，注明请假类型、起止时间、事由。
2. 直属主管审批；年假超过 3 天的须部门负责人加签。
3. 审批通过后系统自动同步考勤记录。

第十条 采购审批流程
1. 需求部门提交采购申请。
2. 金额低于 2000 元的，由部门负责人直接审批。
3. 金额在 2000 元至 10000 元之间的，须采购部门复核。
4. 金额超过 10000 元的，须总经理审批。

==================== 附则 ====================

第十一条 本制度自发布之日起执行，由人力资源部负责解释。
